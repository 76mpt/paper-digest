# Beyond Prediction Gain: LASR as a Metric for Action-Grounded Latents in World Models

- arXiv：https://arxiv.org/abs/2611.17775　｜　出現在日報：[2026-11-17](../digests/2026/2026-11-17.md)　｜　筆記日期：2026-11-18
- 作者／機構：Yu Zhou et al.（機構待查全文）
- Code／專案頁：摘要沒有附
- 讀了哪些部分：**只有摘要**。下面「方法」「數字」的細節待讀全文補上。

## 一句話
latent action 讓未來預測變好，不代表它編碼了動作；它可能只是編碼了目前狀態、episode 進度、任務身分這類「預測捷徑」。現有評估（重建 loss、rollout 品質、動作還原、下游表現）分不開這兩者，所以要用有正負對照的指標去扣掉捷徑。

## 問題設定
- latent action 模型從沒有動作標籤的影片推出類似動作的變數。
- 核心疑慮：預測增益（prediction gain）可以來自「動作以外」的資訊。只看「加了 latent 之後預測變好」，無法判斷 latent 是動作還是狀態的另一種編碼。

## 方法（依摘要）
- **LASR（Latent Action Support Ratio）**：無因次指標，在 held-out 資料上量 latent 對「動作相關目標」的預測支持，**扣掉**目前狀態和非動作替代變數（non-action alternatives）已經能提供的部分。
- 兩個摘要值：GeoLASR（典型情況）、WorstLASR（最弱情況）。
- 協定：動作相關目標 = 記錄的動作與對應的物理狀態變化；episode-held-out 切分；所有比較用同一種 predictor；設正對照與負對照。
- 用 LASR 訓練並稽核一個輕量 residual adapter，用 paired comparison 評估不確定性。

## 實驗與數字（作者自報）
- 機器人操作的錄製資料與一個 matched 多任務 panel。
- 作者自報：LASR 能偵測已知的動作資訊、拒絕代表性的非動作捷徑、能對不完美的 latent 分等級比較；adapter 的點估計「descriptively better」（作者自己的措辭，沒宣稱顯著）。
- 具體數字摘要沒有給，待查全文。

## 和我方向的關係

### 這篇的評估判斷和我們在 RAC 得到的判斷相似（重點）
LASR 的核心論點是：**一個條件變數讓表現變好，不等於模型用到了這個變數「該有的內容」；要用對照把「其他來源的資訊」扣掉才能下結論。** 這和我們在 Revisiting ESC 的 finding 2（exemplar 貢獻）是同一個判斷，只是條件變數不同：

| | LASR（latent action） | 我們（ESC 的 exemplar） |
|---|---|---|
| 條件變數 | latent action z | exemplar 影片片段 |
| 表面證據 | 加了 z 預測變好 | 用 exemplar 訓練，test MAE 比 \|S\|=0 好 |
| 疑慮 | z 可能只編碼了目前狀態、進度、任務身分 | exemplar 的好處可能不是來自它「示範了哪個動作」，而是一般性的效果（例如多一次對真實影片 token 的 cross-attention、正則化） |
| 對照手段 | 扣掉目前狀態與非動作替代變數；正負對照；同一 predictor；episode-held-out；paired 比較 | swap probe（換成其他類別的 exemplar）；\|S\|=0 訓練；self-clip（換成同一支影片的隨機片段）；同 checkpoint on/off；paired 檢定 |
| 結論型態 | 「預測增益 ≠ 動作」 | 「exemplar 貢獻小，且不是 content-specific」 |

我們這邊的證據狀態（來自 `context/memory/project_revisiting_esc.md` 的快照，以那裡為準）：
- **已驗證**：swap probe：換成其他類別的 exemplar，official 和我們的 control 的 MAE 幾乎不變（差 ≤ 0.01），推論時 exemplar 的**內容**沒有被用到。
- **已驗證（n=3 vs 3）**：在 ESC 的評估協定（有 overlap TTA）下，用 exemplar 訓練比 |S|=0 好約 0.015；不用 overlap 時沒有差別。
- **假說，待 self-clip 結果**：exemplar 訓練的好處是一般性的（多了對真實影片 token 的 cross-attention），而不是 exemplar 的內容。self-clip 臂就是我們的「非動作替代變數」對照，角色等同 LASR 的負對照。
- 另一個同型的發現：warm-start 的 generic 效應汙染子集顯著性（`phd_world_model_roadmap.md` §2）：表面上是某個模組的效果，其實來自初始化。

**可以怎麼用**
- 計畫書和先導論文的方法論段落可以這樣寫：「條件變數帶來的增益必須扣掉非內容來源才算數」這個判斷，我們在 RAC 上已經用 swap probe、|S|=0、self-clip 做過一次，LASR 在 latent action 上獨立提出同樣的要求。這能支撐「RAC 的評估方法論可以轉移到世界模型」的主張（`phd_direction_memo.md` §4 的評估方法論那一列）。
- 我們的對照手段可以補 LASR 的缺口：LASR 需要記錄的動作當目標；swap 類對照（把 z 換成別的 episode、別的任務、同 episode 別的時間點的 z）**不需要動作標籤**，可以用在人體影片上。

### 可以直接借用
- 協定：同一種 predictor、episode-held-out、正負對照、paired 比較、典型值與最差值分開報。A 版「latent action 對真動作的線性探針」直接改成 LASR 式寫法，不要只報探針準確率。
- WorstLASR 的想法：除了平均，報最差的那個情況。和我們 Q1–Q4 分位分析報最差分位是同一個習慣。

### 威脅或差異點
- 不直接威脅 novelty：這篇沒有週期動作、計數器、世界模型 rollout 的長程漂移。
- 但「latent action 的評估方法論」這個位置有人佔了一部分，先導論文若要談 latent action 評估，必須引用並比較它。

### 待驗證的想法（假說）
- **H1：在週期任務上，「進度」和「第幾下」綁在一起，LASR 扣掉進度時可能把真正的動作資訊也扣掉。** 「重複動作對應重複碼」的先驗會讓同一個碼在第 1 下和第 5 下出現，這是動作；但如果碼還帶了「第幾下」，那就是進度捷徑。要分開這兩者，可以用「同一個動作相位、不同次數」的配對當對照。這也可能是一個小貢獻：週期版的 LASR。
- **H2：用 Track B 的關節角度變化量當 LASR 的動作目標**，就可以在沒有機器人動作標籤的人體影片上算 LASR。需要先確認 MediaPipe 的雜訊不會讓所有 latent 的 LASR 都偏低。
- **H3：把 ESC 的 exemplar 當成「條件變數」算一個 LASR 式的指標**（exemplar 對計數提供多少超出影片本身的支持），可能會得到和 swap probe 一致的「接近零」。如果成立，碩論的 finding 2 可以多一個和世界模型文獻同一語言的量化結果。
